# What is RGBA
Red, green, blue, alpha, is a commonly used color system where each letter corresponds to a color value. RGB represent the ratios of Red, Green, Blue, while alpha represents the translucency of the pixel. 

# Representations
There are three common ways to represent RGBA. First is normalized floats with values between 0 and 1 . For example (0.7, 0.2, 0.4, 1). 

Another is to use between 0 and 255 to represent strength of a particular color. For example (142, 31, 200, 255). This is because a [[Char]] is bounded between 0-255. This is commonly used with [[Hexadecimal]] in the form #RRGGBBAA.
