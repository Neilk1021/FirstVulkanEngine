# What is the Input Assembly?
>The input  assembly describes *what* the vertices you're giving it are trying to represent. 
## Topologies
---

| Topology Type                           | Description                                                                                                                                                                                                                                                                                                                                                                |
| :-------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `vk::PrimitiveTopology::ePointList`     | This is a list of points and the vertices are just that, not forming any further complex geometry.<br><br>**Example:** (a), (b), (c), (d)                                                                                                                                                                                                                                  |
| `vk::PrimitiveTopology::eLineList`      | This is a list of lines defined by two vertices. So, every two elements is a pair  <br><br>**Example:** (a1, a2), (b1, b2).                                                                                                                                                                                                                                                |
| `vk::PrimitiveTopology::eLineStrip`     | This is a list of lines, but the lines are contiguous and continue one after another, this is more efficient as there is less duplication. <br><br>Example: (a1, a2), (a2, b1), (b1, b2)                                                                                                                                                                                   |
| `vk::PrimitiveTopology::eTriangleList`  | This is a list of triangles where every three vertices defines one triangle. **This is the one virtually used everywhere.**<br><br>**Example:** (a1, a2, a3), (b1,b2,b3)                                                                                                                                                                                                   |
| `vk::PrimitiveTopology::eTriangleStrip` | This is a list of triangles where every three vertices defines a triangle but we use a sliding window to kick one vertex out and replace it as we iterate through the list. <br><br>Fixes the duplicate data problem but in practice extremely hard to implement (for complex 3d models). Winding order also gets swapped. <br><br>**Example:** (a1, a2, a3), (a3, a2, b1) |
## Primitive restart
> This is basically our EOF marker but for objects. It 16bit its `0xFFFF` and in 32bit its `0xFFFFFFFF` (max value). This tells our index that this object is done and to move onto the next one. (This is used to prevent large ugly connections between objects).
